## Submission Procedure

1. Collaborate on the **complete assignment document** (WBS, Gantt, risk analysis, requirements, diagrams, test cases, etc. belong in its relevant sections). No separate file per section is required.
2. Include **Member Contribution** (total 100%) and **AI Usage Log** within each graded PA; check that claims are supported by real evidence.
3. Submit both PDF and editable source via **Moodle** according to the official due date and format.
4. Commit the matching PDF and editable file here, for example `pa/PA1/T05-PA1.pdf` and `pa/PA1/T05-PA1.docx`.
5. Treat a submitted PA as a **baseline**. Do not silently overwrite the historic copy to make later work look like it was submitted earlier.

Working drafts may live in Google Docs/Drive; GitHub Issues/Projects and [weekly reports](../docs/management/weekly/README.md) provide the ongoing contribution and progress record. The presence of a README **does not indicate that a PA has already been submitted**.
