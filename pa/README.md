## Submission rules

- Use **the official provided template**, then submit **both PDF and editable source** to Moodle; commit copies to this repository.
- Recommended names: `T05-PA1.pdf` and `T05-PA1.docx` (follow any more specific TA rule).
- Include the **Member Contribution** table and **AI Usage Log** in each graded PA (PA1–PA5) and verify facts.
- Submit by the official Moodle deadline; the course guidelines specify penalties for late submission.
- **Do not rewrite previously submitted PA snapshots** to disguise changes. If a change is approved after a phase gate, keep a clearly named revised copy plus a dated change log with impacted downstream documents.
- The submitted PA becomes the reference baseline for subsequent phases.

The presence of a folder or README is **not proof** that its PA has been submitted or approved.
