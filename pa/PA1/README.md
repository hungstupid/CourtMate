# PA1 — Project Proposal & Plan (Initiation and Planning)

Store the **submitted** PDF + editable source, team contribution evidence/assessment and required AI Usage Log (within the submitted document). **Deadline:** end of W3 per course guide; verify the Moodle date.

Required sections from the official template:
1. **Vision:** preliminary problem/operating environment and constraints, product position, stakeholders/users, MoSCoW features, explicit out-of-scope.
2. **Proposed Solution:** C4 System Context, justified stack, hardware and operating environment.
3. **Project Plan:** waterfall phase gates, WBS at least 3 levels, person-hour estimates and method, Gantt with dependencies/milestones/critical path, roles with backups, personnel/tool/hosting costs.
4. **Risk Management:** at least 5 risks, lecture-based **RE=P×Loss**, mitigation/contingency and owner.
5. **Tools & Collaboration:** GitHub Project board, owned/due-dated issues, repository, PR review/protection, official TA-accessible channel and W2–W10 weekly report workflow.
6. **Member Contribution** (100% total) and **AI Usage Log**.

Living drafts, WBS, Gantt and risk register belong to `docs/management/`, designs in `docs/design/`. Do not pass estimated values off as actuals. Only commit the final approved/submitted snapshot here.
