# AI usage disclosure — every PA

Record **significant** assistance from ChatGPT, Claude, Gemini, Copilot or similar tools. AI may help brainstorm, draft, explain, review, implement or propose tests; a team member must verify every output.

Include in each record: PA/phase, date, member, tool, task/purpose, the **specific changes made after human review**, linked deliverable/PR/Issue, and any unresolved concerns. The PA submission itself must contain the phase's AI Usage Log according to course policy.

Do not fabricate reviews, interviews, tests, usage records or outcomes. Never paste private information, credentials or student identity numbers into a public AI log.

Use one file per phase, such as `PA2-AI-Usage.md`; keep early drafts here and the submitted snapshot inside `pa/PAx/`. If truly no AI was used for a PA, write **"No AI tools were used"** in that PA's required log.
