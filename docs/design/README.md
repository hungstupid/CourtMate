# Design — all phases

Store design documents that explain **how approved requirements will be implemented**: C4 System Context/Container, component/deployment views, architecture decision records (ADR), UML class/sequence/state diagrams, ERD/table specifications, database constraints/indexes, UI flows, screen specifications and accessibility considerations.

- PA1: **preliminary C4 System Context** and proposed stack rationale.
- PA3: detailed architecture, ≥3 justified ADRs, object-oriented and data design, interface definitions and UI design.
- PA4–PA5: record approved design changes and links to implementation/test evidence.

Each major choice includes context, considered alternatives, decision, trade-offs, owner/date and status (proposed/accepted/superseded). Keep diagram sources editable when possible. Booking concurrency protection must align with requirements, not assumptions.

Do not put generated application code or submitted PA PDFs here.
