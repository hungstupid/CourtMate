# Plans, WBS and risk management — all phases

Use this folder for **living, versioned project planning artifacts**, beginning in PA1 and maintained through PA5/Final:

- `WBS.*`: at least three levels (phase → deliverable → assignable work package); every leaf has a unique WBS ID, owner, estimated **person-hours** and a GitHub Issue link.
- `schedule.*`: Gantt, actual calendar dates, milestone/PA gates, dependencies, duration vs effort, identified **critical path**, buffer and revisions.
- `effort-cost.*`: estimation method (three-point, analogy or expert judgement), assumptions, rate × effort, tools/hosting cost and change history.
- `risk-register.*`: ≥5 risks with category, Probability, Loss, **Risk Exposure = P × Loss**, owner, trigger, mitigation, contingency and status. Use the scoring scale required by the lecture.
- `roles-and-contributions.*`: primary/backup roles, proposed percentages totaling 100%, linked evidence.
- `change-log.*`: changes to scope, schedule, architecture or baselined requirements, with approval and impacted artifacts.

The GitHub Project board and linked Issues track **current task status**; these documents capture the rationale/estimates. Do not treat proposed numbers as actual effort. Freeze the submitted snapshot separately under `pa/PA1/`.
