# Meeting minutes and TA communication — all phases

Store one record per actual team/TA meeting: `YYYY-MM-DD-topic.md` (e.g., `2026-10-12-PA1-kickoff.md`).

Use [MEETING_MINUTES_TEMPLATE](../templates/MEETING_MINUTES_TEMPLATE.md). Include **date/time, attendees/absentees, agenda, options considered, decisions vs open questions, action owner and due date, issue links**, TA feedback and next meeting.

Scope, booking rules, tech stack, estimated workload and contributor percentages must be labeled **proposed** until discussed and agreed. If TA approval is pending, record that explicitly; do not turn a question into a decision.

Decisions that affect previously submitted PAs should also be recorded in the decision/change log and referenced in later PAs. Messenger/Discord messages are not a substitute for a reviewable decision record.
