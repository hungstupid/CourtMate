# Member contributions and evidence — all phases

Use this folder to record **transparent and verifiable** contributions for each PA and teamwork reviews.

For each student keep: member, agreed role(s), planning percentage, actual work, evidence links (assigned WBS issues, PRs, commits, reviews, document changes, test records, meeting work), challenges, and an agreed/TA-reviewed assessment.

- Planned contribution percentages **must total 100%** in the PA1 table; equal 25% values are not proof of equal effort.
- Reassess actual contributions when submitting each graded PA, based on accepted outputs/evidence; do not invent percent distributions or signatures.
- Do not copy student IDs, emails or private personal data here unless required and appropriate for a public repository.
- Unresolved disagreements belong in a factual meeting record and should be escalated to the TA under the team contract when necessary.

Submitted per-PA Member Contribution tables live with each PA's submission in `pa/PAx/`. GitHub history provides evidence rather than an automatically calculated grade.
