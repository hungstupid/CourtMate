# Management Records

This directory exists primarily to support **traceable teamwork**, not to duplicate the PA1 document.

Required recurring content:
- [`weekly/`](weekly/README.md): one real weekly status report for every week W2–W10.

Optional content, if needed:
- `YYYY-MM-DD-meeting.md`: attendance, decisions, TA feedback and action owner/due date.
- `decision-log.md`: major changes to approved scope or previously submitted PA baselines.

**Do not create separate files** for WBS, Gantt, risk register, cost estimate or Member Contribution simply because those items appear in a PA template. Include them in the relevant PA document. Track owners, deadlines and current status in **GitHub Issues/Projects**; use PRs, document revision history and reports as contribution evidence.
