# Infrastructure and deployment — all phases

Store **versioned, non-secret** deployment infrastructure here once the deployment approach is approved: Docker files/compose, infrastructure-as-code, environment templates and reproducible deployment notes. Hosting/provider choices from PA1 are **proposals** until accepted.

Expected documentation when available: service architecture, environment variable **names**, local vs hosted environment differences, deployment steps, rollback and smoke-test procedure. Link to CI workflows in `.github/workflows/`.

Do **not** store live API keys, credentials, production database exports, paid service tokens, personal data, screenshots of secrets or fabricated deployment evidence. Record actual deployment test results under `docs/test/`; record final release evidence under `pa/PA5/`.
